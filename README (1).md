# MADO DESARROLLO

Base del sitio de MADO / SYSTEM.

## Arquitectura

- `public/` — sitio público
- `admin/` — futuro panel privado
- `functions/` — endpoints / lógica de Cloudflare Workers
- `database/` — esquema para Cloudflare D1
- `public/assets/` — identidad, imágenes, iconos y tipografías

## Principio

El código define la interfaz y la base de datos define el contenido.
Los proyectos, documentos legales y enlaces deberán administrarse desde `/admin`
cuando conectemos el backend.
